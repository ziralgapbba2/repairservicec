저장 방식

입력한 내용은 이 브라우저에 자동 저장됩니다. 다른 사람이나 다른 PC에서도 같은 데이터를 보려면 GitHub의 파일을 바꿔야 합니다.
  1. 데이터 포함 HTML 다운로드를 누릅니다. 현재 데이터가 들어간 HTML 파일이 받아집니다.
  2. GitHub 리포지토리에서 기존 파일을 받은 파일로 덮어써서 커밋합니다 (파일명 동일하게).
  3. 몇 분 뒤 GitHub Pages 주소로 접속하면 모두에게 새 데이터가 보입니다.
